# 紹介動画　構成と生成手順

`docs/紹介動画_CareShift_Guard.mp4`（1920×1080 / 2分57秒 / 約4.4MB）の内容と、
作り直したいときの手順をまとめる。

外部の動画共有サービスには投稿しない。発表スライドの最終ページに
`addMedia` で実体ごと埋め込むため、通信環境に依存せず再生できる。

---

## 何を映しているか

ローカル Docker で稼働している CareShift Guard を Chrome で実際に操作し、
その各段階の画面をそのまま並べている。架空の画面や図解ではない。

字幕は動画に焼き込んである（画面下の帯）。切り替えたい場合に備えて
`docs/紹介動画_CareShift_Guard.srt` も同時に出力する。
PowerPoint は埋め込んだ動画にキャプションを紐づけられる。

画面収録ではなく静止画を並べている理由は3つ。

1. 説明文の分量と表示時間を確実に制御できる。読み切れない速さにならない
2. 同じ入力から常に同じ動画が出る。撮り直しが要らない
3. 静止画中心なので H.264 がよく効き、pptx に埋め込める容量に収まる

## 作り直す手順

```bash
# 1. ローカルで起動して証跡を取る
make demo

# 2. 稼働画面を撮影して docs/images/ に置く
#    ファイル名は上の表のとおり。撮り方は docs/デプロイ手順.md 第7節

# 3. Excel を画像化する
make xlsximg

# 4. 証跡テキストを画像化する
make evidence

# 5. 動画と字幕を作る
make pv

# 6. スライドに埋め込む
make slides
```

`make pv` は場面ごとに mp4 を作ってから無再圧縮で連結する。
途中で止まった場合は区間を指定して続けられる。

```bash
python3 -m scripts.build_pv --segments 6 10   # 6〜10 番だけ符号化
python3 -m scripts.build_pv --concat          # 連結して仕上げる
```

## 発表での使い方

発表は5分しかないため、動画を通して流す時間はない。

- 場面5〜6（適合状態と日別の常勤換算）だけを 30 秒ほど再生する
- 残りは提出物として参照してもらう
- 動画を再生できない環境でも、スライド5〜7に同じ画面を静止画で載せてある
